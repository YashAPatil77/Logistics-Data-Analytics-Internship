# Week 3 – Advanced Data Analysis and Visualization

This folder contains the work completed during Week 3 of my Logistics Data Analyst Internship.

## Objective

The objective was to perform Exploratory Data Analysis (EDA) and develop visualizations to identify patterns and relationships in logistics data.

## Main Activities

- Exploratory Data Analysis
- Descriptive statistics
- Central tendency analysis
- Distribution analysis
- Correlation analysis
- Regional performance analysis
- Shipment volume analysis
- Delivery-time analysis
- Transportation-cost analysis
- Logistics performance visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Key Focus

The analysis examined shipment volume, delivery time, transportation cost, distance, delays, and customer-related metrics to support data-driven logistics decisions.
