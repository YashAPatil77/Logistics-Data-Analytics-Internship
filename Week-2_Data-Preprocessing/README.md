# Week 2 – Data Collection, Cleaning, and Preprocessing

This folder contains the work completed during Week 2 of my Logistics Data Analyst Internship.

## Main Activities

- Data collection and dataset understanding
- Data quality assessment
- Missing-value handling
- Duplicate detection
- Outlier detection
- Data normalization
- Categorical encoding
- Feature engineering
- Preprocessing validation

## Objective

The objective was to clean and transform logistics data into a reliable format suitable for Exploratory Data Analysis and predictive modeling.

## Focus

The preprocessing stage focused on improving data quality, consistency, and reliability for downstream logistics analytics.
