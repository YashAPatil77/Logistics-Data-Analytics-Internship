# 📈 Model Evaluation

The predictive models are evaluated using:

### MAE

Mean Absolute Error measures the average absolute difference between actual and predicted delivery time.

### RMSE

Root Mean Squared Error gives greater importance to larger prediction errors.

### R²

R-squared measures how much of the variation in delivery time is explained by the model.

### Cross-Validation

Five-fold cross-validation is used to evaluate model stability across multiple data splits.

### Hyperparameter Tuning

GridSearchCV is used to evaluate different Random Forest parameter combinations and identify a suitable configuration.

---

# 🚚 Logistics Optimization Strategies

The predictive analysis can support several operational strategies.

### 1. Route Planning

Review feasible shorter routes for shipments with higher predicted delivery times while considering operational constraints.

### 2. Shipment Consolidation

Group compatible shipments by geography and delivery windows to improve vehicle utilization.

### 3. Vehicle Utilization

Improve vehicle loading and utilization to reduce unnecessary transportation capacity.

### 4. Warehouse Load Balancing

Monitor warehouse workload and redistribute operational capacity where feasible.

### 5. Delivery Exception Management

Create alerts for shipments whose predicted delivery time exceeds a predefined service target.

### 6. Resource Allocation

Allocate additional operational resources to areas where elevated delivery times are predicted.

### 7. Transportation Cost Analysis

Evaluate route distance, vehicle utilization, and transportation cost together when comparing feasible logistics plans.
