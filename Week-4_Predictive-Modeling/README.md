# Week 4 – Predictive Modeling and Optimization

This folder contains the work completed during Week 4 of my Logistics Data Analyst Internship.

## Objective

The objective was to develop predictive models for logistics delivery-time forecasting and propose optimization strategies based on predictive insights.

## Predictive Models

- Linear Regression
- Decision Tree Regression
- Random Forest Regression

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)
- Cross-validation

## Optimization Areas

- Route planning
- Shipment consolidation
- Vehicle utilization
- Warehouse load balancing
- Resource allocation
- Transportation cost optimization

## Key Outcome

A hypothetical logistics dataset was used to develop and evaluate predictive models for delivery-time forecasting. The analysis demonstrates how predictive insights can support proactive logistics planning and operational optimization.

## Note

The dataset and numerical results in this project are simulated for internship and academic demonstration purposes.
